# Velkina Visual Identity — v9 Maximalist (LOCKED 2026-06-02)

Four mandatory commitments (design-creativity-engine discipline). These are non-negotiable for the build.

## 1. CANVAS COMMITMENT — "Terminal Black / Voltage"
Concept canvas with a POV, not a gradient. Velkina builds AI systems and ships real software — the canvas is a **live machine**, not a brochure.
- **Base:** near-black graphite `#0A0B0D` (not pure black — has warmth). Deep ink layer `#121316`.
- **Paper/contrast surface:** bone `#EDEAE3` for the rare inverted section (the "we're not just dark-mode default" move).
- **ONE high-voltage accent:** electric lime-citron `#C6F24E` (signals frontier/energy, reads "compiler output / live signal", NOT the purple-AI cliché). Used surgically — on the signature text, key CTAs, cursor, live indicators.
- **Secondary signal:** a cold machine cyan `#5BE6D8` used ONLY for "live/real" data states (real client tags, live metrics), never decoratively.
- **Texture:** subtle film grain + a single committed post-process look = **ordered/Bayer DITHERING** on the hero canvas (chosen over ASCII/halftone — dithering reads "rendered, computed, retro-future" and is GPU-parallel/cheap). This is the committed look.

## 2. TYPE IDENTITY
One display voice + one workhorse + one mono. No Inter/Roboto/Space-Grotesk-as-display.
- **Display:** a grotesque with attitude — **"Anton"** is overused; use a **variable grotesk** so we can do the proximity-morph move. Choose **"Archivo" (variable, expanded weights/widths)** OR self-host a distinctive grotesk. Display set MASSIVE (clamp up to 12-16vw), tight tracking, the signature kinetic/variable hero.
- **Body/UI:** a clean neo-grotesque — system stack fallback + self-host **"Geist"** (Vercel's, fitting for a dev studio) for body.
- **Mono:** **"Geist Mono"** / **"JetBrains Mono"** — used for labels, the "live" data, code-feel eyebrows, the terminal motif. Mono is part of the brand voice (dev studio).
- **Hierarchy rule:** numbers and real data get the mono+voltage treatment (Adobe-Spectrum big-number energy). Never 14px gray subhead for important facts.

## 3. SIGNATURE VISUAL MOVE
**"VELKINA" rendered as living MSDF text that the cursor disturbs — letters built from a particle/voxel field that scatters on velocity and reforms, dithered, on the WebGPU/TSL compute path.**
- Hero: the wordmark VELKINA materializes from a dust/particle field, holds, and reacts to cursor velocity (scatter → reform). Scroll dissolves it into the next scene.
- Across the site (persistent canvas): the same particle system morphs into section motifs — a globe of project nodes, a flowing data-pipeline ribbon, a constellation of the two operators.
- Cheapest sitewide echo: **variable-font proximity morph** on all big headings (weight/width shifts toward the cursor). Ties everything to the hero's "alive under the pointer" language.
- The make-of is part of the brand: a tasteful "/process" or footer note that the site is hand-built on the frontier stack = proof for an AI-dev studio.

## 4. ANTI-PATTERNS — BANNED
- ❌ Purple/pink gradients on white (the AI-startup cliché).
- ❌ The generic three.js starter: tunnel + drifting particles + OrbitControls hero. (AI-commoditized — reads as template.)
- ❌ 3-up feature card grid as the primary layout.
- ❌ Inter/Roboto/Space Grotesk as the display face.
- ❌ Fabricated metrics as decoration (120 projects, 95% CSAT — banned, they were fake).
- ❌ Stock "team" avatars / invented persona faces.
- ❌ Springy default eases; bouncy hover. Use editorial curves only.
- ❌ Five accent colors. We have ONE voltage + ONE machine-signal, used with restraint.
- ❌ Position-driven cheap interactivity. VELOCITY drives the magic.
